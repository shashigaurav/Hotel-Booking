# 🏨 Hotel Booking System — Backend

Spring Boot backend for Hotel Booking System.

## 🔗 Live Demo
👉 https://hotel-booking-msg.netlify.app/

## 🛠️ Tech Stack
- Java, Spring Boot, Spring Security
- Hibernate/JPA, MySQL
- JWT Authentication
- REST APIs (15+ endpoints)

## ✨ Features
- JWT-based Authentication & Authorization
- Room Management & Booking APIs
- Transaction-safe Concurrent Booking
- Spring Security Integration
- Normalized MySQL Database Schema

## ⚙️ Run Locally
mvn spring-boot:run
